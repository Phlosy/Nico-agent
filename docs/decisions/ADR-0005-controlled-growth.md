# ADR-0005：候选驱动的受控成长

- 状态：Accepted
- 日期：2026-07-16

## 背景

平台目标是让 Agent 从轨迹中学习，但自动记忆、技能或配置变更可能造成污染、权限升级和不可复现。

## 问题

如何实现“越用越好”，同时保证可验证、可审批、可回滚和可追溯。

## 候选方案

1. Agent 直接改写正式 Memory、Skill 和 Prompt。
2. 所有内容都必须人工手写。
3. 自动生成 Candidate，经验证、评价、审批、发布、灰度和回滚后成为正式版本。

## 最终选择

选择方案 3。自动生成永远先进入 Candidate；发布创建不可变版本并切换 active pointer，旧版本保留。

## 选择原因

保留自动提炼的复利价值，同时把错误经验、提示注入和短期偶然成功隔离在正式能力之外。

## 代价

成长速度低于直接自改；需要评价数据集、审批队列、版本统计和过期/冲突处理。

## 后续影响

Goal F 实现 Memory/Skill Candidate、Evaluation 和 Approval。单次成功率或收益不得单独触发发布。

## 可逆性

高。发布通过 active pointer 回滚；Candidate 可以废弃且保留审计，评价规则可版本化演进。
