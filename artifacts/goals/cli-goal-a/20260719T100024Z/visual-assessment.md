# Coin-cat visual assessment

The README asset `docs/assets/nico-logo.png` was inspected at its original 512 × 512 resolution.

Observed brand traits:

- transparent background and a centered cat face;
- coarse pixel-block silhouette;
- muted grey-blue shadow and outline;
- soft gold/beige main fur;
- warm-white forehead stripe, muzzle and chest;
- dark round eyes and a small pink nose.

Three terminal candidates are archived in `coin-cat-candidates.txt`. Candidate A, the 19-column by 9-row pixel coin, was selected. It preserves the coin silhouette, ears, eyes and central white stripe with four Rich color roles. Candidate C is only the narrow-terminal fallback. No emoji or terminal image protocol is required.

This is an inspired-by terminal redesign, not a pixel-identical conversion of the PNG. Goal A contains no logo rendering business code; Rich rendering belongs to CLI Goal D.
